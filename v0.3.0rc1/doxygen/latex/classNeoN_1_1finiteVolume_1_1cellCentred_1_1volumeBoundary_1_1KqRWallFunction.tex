\doxysubsection{Detailed Description}
Zero-\/gradient wall BC for turbulent kinetic energy k (and q, R). 

Mirrors Open\+FOAM\textquotesingle{}s kq\+RWall\+Function\+Fv\+Patch\+Field, which upstream derives from zero\+Gradient\+Fv\+Patch\+Field and explicitly states it is not a wall-\/function. Registered under the name {\ttfamily "{}kq\+RWall\+Function"{}} so Open\+FOAM dictionaries with that type string work unchanged.
