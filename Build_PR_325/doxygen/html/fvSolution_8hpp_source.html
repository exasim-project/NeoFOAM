24/* @brief Look up the equation under-relaxation factor for a field from fvSolution.
25 *
26 * Parses the OpenFOAM `relaxationFactors.equations` sub-dictionary and returns the
27 * scalar relaxation factor for the given field. When `finalIter` is true the
28 * `<field>Final` key is preferred (Final-suffix seam), falling back to the base
29 * `<field>` key. Returns std::nullopt when no entry exists -> the caller uses 1.0 ->
30 * the kernel is a no-op (matches OpenFOAM's "no entry, no relax" semantics).
31 *
32 * Keeping this parsing in NeoFOAM means NeoN's applyMatrixRelaxation only ever
33 * sees a plain scalar; NeoN stays OpenFOAM-dictionary-agnostic.
34 *
35 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
36 * @param field The field name (e.g. "U").
37 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
38 */
39std::optional<NeoN::scalar>
40lookupEqnRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);

42/* @brief Look up the explicit field under-relaxation factor for a field from fvSolution.
43 *
44 * Parses the OpenFOAM `relaxationFactors.fields` sub-dictionary and returns the scalar
45 * relaxation factor for the given field. When `finalIter` is true the `<field>Final` key is
46 * preferred (Final-suffix seam), falling back to the base `<field>` key. Returns
47 * std::nullopt when no entry exists -> the caller uses 1.0 -> the kernel is a no-op (matches
48 * OpenFOAM's "no entry, no relax" semantics).
49 *
50 * `relaxationFactors.equations` and `relaxationFactors.fields` are independent dicts:
51 * a field present only under `equations` (e.g. momentum `U`) returns nullopt here, so
52 * field-URF is a no-op on it and momentum is never double-relaxed. Shares the int-tolerant,
53 * isDict-guarded lookup body with lookupEqnRelaxation.
54 *
55 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
56 * @param field The field name (e.g. "p").
57 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
58 */
59std::optional<NeoN::scalar>
60lookupFieldRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);
