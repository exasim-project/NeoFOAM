Detailed Description

NeoFOAM-level wrapper for the standard k-ε turbulence model (Launder & Spalding 1974).

Mirrors the OpenFOAM turbulence->validate() / turbulence->correct() interface and follows the same layout as KOmegaSST. Owns all intermediate fields and cached operators; the solver manages the primary fields (k, ε, ν_t) and calls validate() once at setup and correct() after each momentum solve.

Equations:

ν_t = Cμ k²/ε

∂k/∂t + ∇·(φ k) - ∇·((ν + ν_t/σ_k) ∇k) = G - ε ∂ε/∂t + ∇·(φ ε) - ∇·((ν + ν_t/σ_ε) ∇ε) = (C1 G - C2 ε) ε/k

Coefficients are the upstream defaults from kEpsilon.C (Cμ=0.09, C1=1.44, C2=1.92, σ_k=1.0, σ_ε=1.3).
