\doxysubsection{Detailed Description}
Neo\+FOAM-\/level wrapper for the standard k-\/ε turbulence model (Launder \& Spalding 1974). 

Mirrors the Open\+FOAM turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1KEpsilon_afeb8fce294681e34c0a47d4ab61df34c}{validate()} / turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1KEpsilon_ad020d2f72910e94b9ee5a42dbf3e86fd}{correct()} interface and follows the same layout as \doxylink{classNeoFOAM_1_1KOmegaSST}{KOmega\+SST}. Owns all intermediate fields and cached operators; the solver manages the primary fields (k, ε, ν\+\_\+t) and calls \doxylink{classNeoFOAM_1_1KEpsilon_afeb8fce294681e34c0a47d4ab61df34c}{validate()} once at setup and \doxylink{classNeoFOAM_1_1KEpsilon_ad020d2f72910e94b9ee5a42dbf3e86fd}{correct()} after each momentum solve.

Equations\+:

ν\+\_\+t = Cμ k²/ε

∂k/∂t + ∇·(φ k) -\/ ∇·((ν + ν\+\_\+t/σ\+\_\+k) ∇k) = G -\/ ε ∂ε/∂t + ∇·(φ ε) -\/ ∇·((ν + ν\+\_\+t/σ\+\_\+ε) ∇ε) = (C1 G -\/ C2 ε) ε/k

\doxylink{structNeoFOAM_1_1KEpsilon_1_1Coefficients}{Coefficients} are the upstream defaults from {\ttfamily k\+Epsilon.\+C} (Cμ=0.\+09, C1=1.\+44, C2=1.\+92, σ\+\_\+k=1.\+0, σ\+\_\+ε=1.\+3).
