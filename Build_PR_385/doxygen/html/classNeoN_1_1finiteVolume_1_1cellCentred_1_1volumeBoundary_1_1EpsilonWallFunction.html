Detailed Description

Turbulent dissipation rate wall function BC.

Mirrors Foam::epsilonWallFunctionFvPatchScalarField: blends viscous and log-layer ε estimates (BINOMIAL n=2) and sets the wall face value.

Required BoundaryContext fields:

  • "k" VolumeField<scalar> — turbulent kinetic energy
  • "nu" VolumeField<scalar> — laminar viscosity, boundary values
  • "nearWallDist" VolumeField<scalar> — cell-to-wall distance y, boundary values

Single-patch-corner only (cornerWeights == 1). G feedback is handled by the parent KEpsilon model, not by this BC.
