\doxysubsection{Detailed Description}
Represents a bijective mapping between an old and a new index space. 

A \doxylink{classNeoFOAM_1_1Permutation}{Permutation} is an immutable valule type that describes how a set of entities is renumbered without modifying or reordering the associated data.

For a permutation of size {\ttfamily N\+:} 


\begin{DoxyItemize}
\item Every old index in \mbox{[}0, N) maps to exactly one new index in \mbox{[}0, N).
\item Every new index in \mbox{[}0, N) maps to exactly one old index in \mbox{[}0, N).
\item {\ttfamily old\+To\+New} and {\ttfamily new\+To\+Old} are inverse mappings.
\end{DoxyItemize}

The class provides both mapping directions so that it can be used fo both reordering entitiy-\/associated data and remapping entity references.

\begin{DoxyNote}{Note}
\doxylink{classNeoFOAM_1_1Permutation}{Permutation} only represents a mapping. It does not compute an ordering and does not apply the mapping to mesh, field, or other CFD data. Ordering algorithms produce \doxylink{classNeoFOAM_1_1Permutation}{Permutation} objects, while permutation application is handled separately by the ordering fraemework. 
\end{DoxyNote}
