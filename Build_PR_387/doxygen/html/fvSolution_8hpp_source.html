26/* @brief Which NeoN::la system matrix format a solver sub-dict selects.
27 *
28 * Picks which PDE<..., SystemMatrixType>/Solver<..., SystemMatrixType> template instantiation
29 * a solver equation (e.g. neoIcoFoam's U or p) should run with. This is a compile-time C++
30 * template parameter, not a Ginkgo setting -- the binary must already have compiled in the
31 * instantiation this selects. See matrixFormat() below for the dictionary entry that picks
32 * between them at startup, independently per equation.
33 */
34enum class MatrixFormat
35{
36 CSR,
37 ELL
38};
39
40/* @brief Look up which matrix format (CSR or ELL) a solver sub-dict selects.
41 *
42 * Parses the "matrixFormat" entry of a per-field solver sub-dict (e.g. solvers.p.matrixFormat,
43 * solvers.U.matrixFormat) -- each equation picks its own format independently. Falls back to
44 * @p defaultFormat when the key is absent; callers should pass whatever their application's
45 * matrix format was before this dictionary entry existed (e.g. neoIcoFoam, which used to
46 * hardcode ELL, passes MatrixFormat::ELL as its default so cases without the key keep running
47 * exactly as they did before this option existed). There is no project-wide default: an
48 * application with no prior hardcoded format should pass MatrixFormat::CSR, matching
49 * NeoN::la::PDE/Solver/LinearSystem's own default SystemMatrixType template argument.
50 *
51 * Only the base "p"/"U" sub-dicts are read for this -- NOT "pFinal"/"UFinal". Matrix format is
52 * a compile-time template parameter fixed once for the whole run (see runCase in neoIcoFoam.cpp),
53 * unlike tolerance/relTol/preconditioner, which pde.hpp's PDE::assemble genuinely does re-read
54 * from "<field>Final" on the last PISO/outer iteration. A "matrixFormat" placed inside a Final
55 * sub-dict is therefore inert: it is stripped by PDE::stripNeoFOAMKeys like any other key headed
56 * for Ginkgo, but nothing ever reads it back out to select a template.
57 *
58 * The key must be stripped before the sub-dict reaches Ginkgo's config parser -- see
59 * PDE::stripNeoFOAMKeys, which callers (e.g. NeoFOAM::Solver::createCachedSolver) already run.
60 *
61 * @param solverDict A per-field solver sub-dictionary (e.g. solvers/p, solvers/U) -- the
62 * base dict, not its Final variant; see above.
63 * @param defaultFormat Format to use when "matrixFormat" is absent.
64 */
65MatrixFormat matrixFormat(const NeoN::Dictionary& solverDict, MatrixFormat defaultFormat);

67/* @brief Look up the equation under-relaxation factor for a field from fvSolution.
68 *
69 * Parses the OpenFOAM `relaxationFactors.equations` sub-dictionary and returns the
70 * scalar relaxation factor for the given field. When `finalIter` is true the
71 * `<field>Final` key is preferred (Final-suffix seam), falling back to the base
72 * `<field>` key. Returns std::nullopt when no entry exists -> the caller uses 1.0 ->
73 * the kernel is a no-op (matches OpenFOAM's "no entry, no relax" semantics).
74 *
75 * Keeping this parsing in NeoFOAM means NeoN's applyMatrixRelaxation only ever
76 * sees a plain scalar; NeoN stays OpenFOAM-dictionary-agnostic.
77 *
78 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
79 * @param field The field name (e.g. "U").
80 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
81 */
82std::optional<NeoN::scalar>
83lookupEqnRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);

85/* @brief Look up the explicit field under-relaxation factor for a field from fvSolution.
86 *
87 * Parses the OpenFOAM `relaxationFactors.fields` sub-dictionary and returns the scalar
88 * relaxation factor for the given field. When `finalIter` is true the `<field>Final` key is
89 * preferred (Final-suffix seam), falling back to the base `<field>` key. Returns
90 * std::nullopt when no entry exists -> the caller uses 1.0 -> the kernel is a no-op (matches
91 * OpenFOAM's "no entry, no relax" semantics).
92 *
93 * `relaxationFactors.equations` and `relaxationFactors.fields` are independent dicts:
94 * a field present only under `equations` (e.g. momentum `U`) returns nullopt here, so
95 * field-URF is a no-op on it and momentum is never double-relaxed. Shares the int-tolerant,
96 * isDict-guarded lookup body with lookupEqnRelaxation.
97 *
98 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
99 * @param field The field name (e.g. "p").
100 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
101 */
102std::optional<NeoN::scalar>
103lookupFieldRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);
