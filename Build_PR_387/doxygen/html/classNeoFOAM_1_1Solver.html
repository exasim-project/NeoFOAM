Detailed Description

template<typename ValueType, typename MatrixValueType = NeoN::scalar, typename IndexType = NeoN::localIdx, typename SystemMatrixType = NeoN::la::CSRMatrix<MatrixValueType, IndexType>>
class NeoFOAM::Solver< ValueType, MatrixValueType, IndexType, SystemMatrixType >

Caches a NeoN::la::Solver instance for a given field to avoid reconstructing it (and re-parsing the solver dictionary) on every time-step iteration.

Usage:

auto uSolver = nf::Solver(U, rt); // once before the time loop
// inside the loop:
nf::PDE<NeoN::Vec3> UEqn(dsl::imp::ddt(U) + ...);
uSolver.solve(UEqn, -1.0 * dsl::exp::grad(p)); // momentum predictor
uSolver.assemble(UEqn); // or explicit assembly only
