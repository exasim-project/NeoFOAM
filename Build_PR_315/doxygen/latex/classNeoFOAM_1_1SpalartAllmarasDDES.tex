\doxysubsection{Detailed Description}
Neo\+FOAM-\/level wrapper for the Spalart-\/\+Allmaras DDES turbulence model. 

Mirrors the Open\+FOAM turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1SpalartAllmarasDDES_a3c0ce97c52d3cc20099747f4728acda0}{validate()} / turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1SpalartAllmarasDDES_a17ab835e02aad16cbe7ddd1d7cf05f4c}{correct()} interface. Owns all intermediate fields and cached operators so the solver only needs to manage the primary fields (nu\+Tilda, nut) and call \doxylink{classNeoFOAM_1_1SpalartAllmarasDDES_a3c0ce97c52d3cc20099747f4728acda0}{validate()} once at setup and \doxylink{classNeoFOAM_1_1SpalartAllmarasDDES_a17ab835e02aad16cbe7ddd1d7cf05f4c}{correct()} after each momentum solve.

Two wall-\/distance fields are required (they are distinct)\+:
\begin{DoxyItemize}
\item wall\+Dist \+: cell-\/centred distances from Foam\+::wall\+Dist\+::y(), used in DDES shielding
\item near\+Wall\+Dist \+: boundary-\/face distances from turbulence\+Model\+::y()\mbox{[}patchi\mbox{]}, used by the nut\+USpalding\+Wall\+Function boundary condition 
\end{DoxyItemize}
