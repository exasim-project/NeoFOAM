Compute the deviatoric stress field for the momentum equation: tau_ij = (nu + nut) * (dev2(gradU^T))_ij = (nu + nut) * (gradU_{ji} - (2/3)*tr(gradU)*delta_ij)

Matches OpenFOAM's: nuEff * dev2(T(gradU)) Returns VolumeField<Tensor> (non-symmetric in general). Used by divDevReff for the momentum viscous term.
