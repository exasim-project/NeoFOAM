Detailed Description

TurbulenceModel-factory wrapper for k-epsilon.

Owns k, epsilon and nut; reads them from disk in the constructor, delegates physics to KEpsilon. Registered as "kEpsilon" in the TurbulenceModel factory so TurbulenceModel::create() can instantiate it from a RAS turbulenceProperties block.
