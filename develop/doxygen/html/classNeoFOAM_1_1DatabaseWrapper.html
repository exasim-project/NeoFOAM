Detailed Description

Registers a NeoN::Database in the Foam::Time objectRegistry.

Allows NeoFOAM functionObjects (which only have const Foam::Time&) to access the NeoN field database via the standard OpenFOAM lookup:

time_.lookupObject<DatabaseWrapper>(DatabaseWrapper::registryName).db()

Lifetime
The wrapper holds a non-owning pointer to its associated NeoN::Database, which must outlive the wrapper. In practice the wrapper is stored as a std::unique_ptr inside RunTime so that its destructor (which calls regIOobject::checkOut) fires before Foam::Time is destroyed.
