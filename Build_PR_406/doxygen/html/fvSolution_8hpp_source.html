95/* @brief Look up the equation under-relaxation factor for a field from fvSolution.
96 *
97 * Parses the OpenFOAM `relaxationFactors.equations` sub-dictionary and returns the
98 * scalar relaxation factor for the given field. When `finalIter` is true the
99 * `<field>Final` key is preferred (Final-suffix seam), falling back to the base
100 * `<field>` key. Returns std::nullopt when no entry exists -> the caller uses 1.0 ->
101 * the kernel is a no-op (matches OpenFOAM's "no entry, no relax" semantics).
102 *
103 * Keeping this parsing in NeoFOAM means NeoN's applyMatrixRelaxation only ever
104 * sees a plain scalar; NeoN stays OpenFOAM-dictionary-agnostic.
105 *
106 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
107 * @param field The field name (e.g. "U").
108 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
109 */
110std::optional<NeoN::scalar>
111lookupEqnRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);

113/* @brief Look up the explicit field under-relaxation factor for a field from fvSolution.
114 *
115 * Parses the OpenFOAM `relaxationFactors.fields` sub-dictionary and returns the scalar
116 * relaxation factor for the given field. When `finalIter` is true the `<field>Final` key is
117 * preferred (Final-suffix seam), falling back to the base `<field>` key. Returns
118 * std::nullopt when no entry exists -> the caller uses 1.0 -> the kernel is a no-op (matches
119 * OpenFOAM's "no entry, no relax" semantics).
120 *
121 * `relaxationFactors.equations` and `relaxationFactors.fields` are independent dicts:
122 * a field present only under `equations` (e.g. momentum `U`) returns nullopt here, so
123 * field-URF is a no-op on it and momentum is never double-relaxed. Shares the int-tolerant,
124 * isDict-guarded lookup body with lookupEqnRelaxation.
125 *
126 * @param fvSolution The parsed fvSolution dictionary (e.g. RunTime::fvSolutionDict).
127 * @param field The field name (e.g. "p").
128 * @param finalIter Whether the final outer iteration is active (selects the *Final key).
129 */
130std::optional<NeoN::scalar>
131lookupFieldRelaxation(const NeoN::Dictionary& fvSolution, const std::string& field, bool finalIter);
