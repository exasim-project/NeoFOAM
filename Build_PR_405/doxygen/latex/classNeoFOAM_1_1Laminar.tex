\doxysubsection{Detailed Description}
No-\/op turbulence model for laminar flow. 

nut is identically zero; \doxylink{classNeoFOAM_1_1Laminar_a81ab1672334a331df04298072c9d5589}{nu\+Eff()} returns the surface-\/interpolated laminar nu. gradU is recomputed each \doxylink{classNeoFOAM_1_1Laminar_aa9b5b6a81ebad82fdda5767eb459a3da}{validate()}/correct() for use in the viscous\+Stress term.
