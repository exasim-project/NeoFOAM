\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type$>$\newline
class Neo\+N\+::finite\+Volume\+::cell\+Centred\+::volume\+Boundary\+::\+Inlet\+Outlet$<$ Value\+Type $>$}
Mixed outflow/inflow BC\+: zero\+Gradient on faces with outward flux, fixed\+Value (inlet\+Value) on faces with inward flux. Mirrors Open\+FOAM\textquotesingle{}s inlet\+Outlet\+Fv\+Patch\+Field. 

Flow direction is determined from the boundary face velocity\+:
\begin{DoxyItemize}
\item For Vec3 fields\+: reads lagged boundary velocity from domain\+Vector.\+boundary\+Data().value().
\item For scalar fields\+: requires "{}\+U"{} in Boundary\+Context; defaults to zero\+Gradient without it. 
\end{DoxyItemize}
