\doxysubsection{Detailed Description}
Base class for \doxylink{namespaceNeoFOAM}{Neo\+FOAM} function\+Objects that produce scalar time-\/series output. 

Inherits Foam\+::function\+Object so that Open\+FOAM\textquotesingle{}s runtime selection table (RTST) can instantiate derived classes directly from control\+Dict\+:

\item \doxylink{classNeoFOAM_1_1FunctionObjectIO_a2a135997dc8957415c3077e11b22557c}{execute()} — runs GPU computation each time-\/step
\item \doxylink{classNeoFOAM_1_1FunctionObjectIO_aa9637f114abb9f1fbf8badbab17d2771}{write()} — writes the scalar result to post\+Processing/ at write intervals
\end{DoxyItemize}

\begin{DoxyParagraph}{GPU-\/aware I/O strategy}
The intent is that GPU computation in \doxylink{classNeoFOAM_1_1FunctionObjectIO_a2a135997dc8957415c3077e11b22557c}{execute()} reduces an entire field to O(1) scalars, which are then transferred to host and written to disk by \doxylink{classNeoFOAM_1_1FunctionObjectIO_aa9637f114abb9f1fbf8badbab17d2771}{write()}. Full field copies to host are never performed inside \doxylink{classNeoFOAM_1_1FunctionObjectIO_a2a135997dc8957415c3077e11b22557c}{execute()}. 
\end{DoxyParagraph}
