\begin{DoxyParagraph}{GPU I/O strategy}
\doxylink{classNeoFOAM_1_1Forces_ad9ae38e7170e3b4a121fb1a0a46d5e2e}{execute()} runs a {\ttfamily parallel\+For} kernel over the boundary patch faces using {\ttfamily Neo\+N\+::atomic\+\_\+add} into a 6-\/element device buffer. Only those 6 scalars (96 bytes) are copied to host — the full pressure field is never transferred. \doxylink{classNeoFOAM_1_1Forces_ab2664062354c5f34078252d7f22dc4ca}{write()} appends one row each to {\ttfamily post\+Processing/} $<$name$>$/$<$start\+Time$>$/force.dat and {\ttfamily post\+Processing/} $<$name$>$/$<$start\+Time$>$/moment.dat.
\end{DoxyParagraph}
\begin{DoxyParagraph}{MPI parallel execution}
Supported. On a decomposed mesh each rank integrates its local slice of the wall patches (patches with no local faces contribute zero); \doxylink{classNeoFOAM_1_1Forces_ad9ae38e7170e3b4a121fb1a0a46d5e2e}{execute()} then globally sums the force/moment contributions so every rank holds the total, and \doxylink{classNeoFOAM_1_1Forces_ab2664062354c5f34078252d7f22dc4ca}{write()} emits the shared output files from the master rank only. 
\end{DoxyParagraph}

Run the GPU force-\/integral computation. 

Looks up the {\ttfamily Neo\+N\+::\+Database} via the {\ttfamily \doxylink{classNeoFOAM_1_1DatabaseWrapper}{Database\+Wrapper}} registered in the {\ttfamily Foam\+::\+Time} object\+Registry, then finds the pressure field {\ttfamily p\+Name\+\_\+} in the {\ttfamily Vector\+Collection}. The field must have been registered by the solver (e.\+g. via {\ttfamily \doxylink{namespaceNeoFOAM_a48fbbbb3755e34d928cf0d189532d93c}{Neo\+FOAM\+::construct\+And\+Register}}) before the first {\ttfamily \doxylink{classNeoFOAM_1_1Forces_ad9ae38e7170e3b4a121fb1a0a46d5e2e}{execute()}} call. Accumulates pressure forces and moments for each registered patch via a GPU-\/parallel kernel; results are stored in \doxylink{classNeoFOAM_1_1Forces_a51ad0e649eabe29078bf8ff6e20324a7}{last\+Result()}.
