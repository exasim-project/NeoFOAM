\doxysubsection{Detailed Description}
GPU-\/accelerated boundary-\/patch force and moment calculator.

\begin{DoxyParagraph}{GPU I/O strategy}
\doxylink{classNeoFOAM_1_1Forces_ad9ae38e7170e3b4a121fb1a0a46d5e2e}{execute()} runs a {\ttfamily parallel\+For} kernel over the boundary patch faces using {\ttfamily Kokkos\+::atomic\+\_\+add} into a 6-\/element device buffer. Only those 6 scalars (96 bytes) are copied to host — the full pressure field is never transferred. \doxylink{classNeoFOAM_1_1Forces_ab2664062354c5f34078252d7f22dc4ca}{write()} appends one row to {\ttfamily post\+Processing/} $<$name$>$/0/force.dat.
\end{DoxyParagraph}
\begin{DoxyNote}{Note}
Viscous forces are not yet implemented (v1 limitation). 

MPI parallel execution is not yet supported (v1 limitation). 
\end{DoxyNote}

GPU kernel\+: accumulate pressure force/moment for one boundary patch. 

Runs {\ttfamily parallel\+For} over faces in the patch range and uses {\ttfamily Kokkos\+::atomic\+\_\+add} into a 6-\/element device accumulator. Transfers 6 scalars to host on completion.

Run the GPU force-\/integral computation. 

Looks up the pressure field {\ttfamily p\+Name\+\_\+} from the {\ttfamily Vector\+Collection} registered in the {\ttfamily Neo\+N\+::\+Database} linked to the {\ttfamily \doxylink{classNeoFOAM_1_1MeshAdapter}{Mesh\+Adapter}}. The field must have been registered by the solver (e.\+g. via {\ttfamily \doxylink{namespaceNeoFOAM_a48fbbbb3755e34d928cf0d189532d93c}{Neo\+FOAM\+::construct\+And\+Register}}) before the first {\ttfamily \doxylink{classNeoFOAM_1_1Forces_ad9ae38e7170e3b4a121fb1a0a46d5e2e}{execute()}} call. Accumulates pressure forces and moments for each registered patch via a GPU-\/parallel kernel; results are stored in \doxylink{classNeoFOAM_1_1Forces_a51ad0e649eabe29078bf8ff6e20324a7}{last\+Result()}.
