\doxysubsection{Detailed Description}
Registers a {\ttfamily Neo\+N\+::\+Database} in the {\ttfamily Foam\+::\+Time} object\+Registry. 

Allows \doxylink{namespaceNeoFOAM}{Neo\+FOAM} function\+Objects (which only have {\ttfamily const} Foam\+::\+Time\&) to access the NeoN field database via the standard Open\+FOAM lookup\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{time\_.lookupObject<\mbox{\hyperlink{classNeoFOAM_1_1DatabaseWrapper_a02cdc14e7b624372b9cf39ca0ba45667}{DatabaseWrapper}}>(\mbox{\hyperlink{classNeoFOAM_1_1DatabaseWrapper_a294a3f7e57e3700663a52e4ef2afe71f}{DatabaseWrapper::registryName}}).\mbox{\hyperlink{classNeoFOAM_1_1DatabaseWrapper_a972ffb40a536ddf575fb0561e4c8c475}{db}}()}

\end{DoxyCode}


\begin{DoxyParagraph}{Lifetime}
The wrapper holds a non-\/owning pointer to its associated {\ttfamily Neo\+N\+::\+Database}, which must outlive the wrapper. In practice the wrapper is stored as a {\ttfamily std\+::unique\+\_\+ptr} inside {\ttfamily \doxylink{structNeoFOAM_1_1RunTime}{Run\+Time}} so that its destructor (which calls {\ttfamily reg\+IOobject\+::check\+Out}) fires before {\ttfamily Foam\+::\+Time} is destroyed. 
\end{DoxyParagraph}
