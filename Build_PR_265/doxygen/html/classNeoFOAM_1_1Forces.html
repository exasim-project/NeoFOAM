Detailed Description

GPU-accelerated boundary-patch force and moment calculator.

Registered in OpenFOAM's runtime selection table under the type name neoForces. Can be driven directly from controlDict:

functions
{
wallForces
{
type neoForces;
libs (NeoFOAM);
patches (fixedWalls);
pName p;
rhoInf 1.0;
pRef 0.0;
CofR (0 0 0);
}
}

GPU I/O strategy
execute() runs a parallelFor kernel over the boundary patch faces using NeoN::atomic_add into a 6-element device buffer. Only those 6 scalars (96 bytes) are copied to host — the full pressure field is never transferred. write() appends one row each to postProcessing/ <name>/<startTime>/force.dat and postProcessing/ <name>/<startTime>/moment.dat.
Note
Viscous forces are not yet implemented; only pressure contributions are computed. OpenFOAM's forces object includes viscous contributions — these will be zero here.
MPI parallel execution is not supported; a FatalError is raised in execute() if Pstream::parRun() is true.

GPU kernel: accumulate pressure force/moment for one boundary patch.

Runs parallelFor over faces in the patch range and uses NeoN::atomic_add into a 6-element device accumulator. Transfers 6 scalars to host on completion.

Parameters
patchiPatch index (positionally consistent with NeoN boundary offset)
nfPNeoN pressure field (on active executor)
rhoRefReference density [kg/m³]
pRefReference pressure [Pa]
cofRCentre of rotation [m]
resultAccumulates into this result (host-side, per-patch contribution added)

◆ execute()

virtual bool NeoFOAM::Forces::execute ( )
overridevirtual

Run the GPU force-integral computation.

Looks up the NeoN::Database via the DatabaseWrapper registered in the Foam::Time objectRegistry, then finds the pressure field pName_ in the VectorCollection. The field must have been registered by the solver (e.g. via NeoFOAM::constructAndRegister) before the first execute() call. Accumulates pressure forces and moments for each registered patch via a GPU-parallel kernel; results are stored in lastResult().

Implements NeoFOAM::FunctionObjectIO.
