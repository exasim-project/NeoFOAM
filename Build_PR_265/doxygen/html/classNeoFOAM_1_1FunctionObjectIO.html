Detailed Description

Base class for NeoFOAM functionObjects that produce scalar time-series output.

Inherits Foam::functionObject so that OpenFOAM's runtime selection table (RTST) can instantiate derived classes directly from controlDict:

functions
{
myForces
{
type neoForces;
libs (NeoFOAM);
...
}
}

Derived classes implement:

  • execute() — runs GPU computation each time-step
  • write() — writes the scalar result to postProcessing/ at write intervals
GPU-aware I/O strategy
The intent is that GPU computation in execute() reduces an entire field to O(1) scalars, which are then transferred to host and written to disk by write(). Full field copies to host are never performed inside execute().
