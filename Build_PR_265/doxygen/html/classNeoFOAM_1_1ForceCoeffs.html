Detailed Description

Normalised aerodynamic force coefficients derived from GPU force integrals.

Extends Forces by dividing the raw pressure forces and moments by the dynamic pressure reference quantities to produce dimensionless coefficients.

Registered as neoForceCoeffs in OpenFOAM's runtime selection table:

functions
{
aeroCoeffs
{
type neoForceCoeffs;
libs (NeoFOAM);
patches (wing);
pName p;
rhoInf 1.225;
pRef 0.0;
magUInf 30.0;
lRef 1.0;
Aref 0.5;
CofR (0 0 0);
}
}

Output columns (forceCoeffs.dat)
# Time Cd.x Cd.y Cd.z Cm.x Cm.y Cm.z
where Cd = pressureForce / (0.5 * rhoInf * magUInf² * Aref) and Cm = pressureMoment / (0.5 * rhoInf * magUInf² * Aref * lRef).
Note
Viscous force contributions are zero in v1.
MPI parallel execution is not yet supported.
