13/* @brief Bounded explicit MULES solve, Foam::MULES::explicitSolve (MULESTemplates.C).
14 *
15 * @detail rho == 1, Sp == Su == 0, static mesh, Euler time step, extremaCoeff ==
16 * boundaryExtremaCoeff == smoothLimiter == 0. As in OpenFOAM, @p alpha (psi, the current
17 * corrector's field) gives the upwind flux phiBD and the local extrema, while @p alphaOld
18 * (psi.oldTime(), alpha at the start of the time step) enters the bound right-hand sides and
19 * the update alpha = (alphaOld*rDeltaT - surfaceIntegrate(alphaPhi))/rDeltaT. Both are the same
20 * field for the first corrector (nAlphaCorr == 1); @p alphaOld may alias @p alpha.
21 * @p phi is the volumetric flux: it defines the upwind (donor) flux and is the BoundaryContext
22 * "phi" for alpha.correctBoundaryConditions, which runs on entry and exit (as in OpenFOAM).
23 * Limits @p alphaPhi in place (high-order flux in, limited flux out) and advances @p alpha
24 * conservatively.
25 *
26 * Boundary treatment (MULES::limiter): patches that fix the value (NeoN fixesValue, plus
27 * inletOutlet, which is a mixed patch and fixesValue() in OpenFOAM) widen the local extrema of
28 * their face cells by the patch value. The boundary correction flux is zero (phiBD_b ==
29 * alphaPhi_b), so the boundary limiter is irrelevant. Coupled (processor) patches throw; wedge
30 * patches do not exist in NeoN.
31 */
32void mulesExplicitSolve(
33 nnfvcc::VolumeField<NeoN::scalar>& alpha,
34 const nnfvcc::VolumeField<NeoN::scalar>& alphaOld,
35 const nnfvcc::SurfaceField<NeoN::scalar>& phi,
36 nnfvcc::SurfaceField<NeoN::scalar>& alphaPhi,
37 NeoN::scalar deltaT,
38 NeoN::scalar psiMax,
39 NeoN::scalar psiMin,
40 int nLimiterIter
41);

43/* @brief MULES::correct (CMULESTemplates.C) for the VoF path, psiMax == 1, psiMin == 0.
44 *
45 * @detail Limits the correction flux @p phiCorr (internal and boundary faces) so that applying
46 * it keeps alpha bounded, then applies it: alpha = (alpha*rDeltaT - surfaceIntegrate(phiCorr))
47 * / rDeltaT. @p phi plays the role of OpenFOAM's limiterCorr phi argument (interFoam passes
48 * alphaPhiUn): a boundary face is limited only where phi_b + phiCorr_b > SMALL^2 (outlets).
49 * Fixed-value / inletOutlet patches widen the local extrema as in mulesExplicitSolve; coupled
50 * patches throw. @p relaxOld blends the result with the pre-correction field (interFoam
51 * aCorr > 0 branch, 0.5); 0 disables it.
52 *
53 * Unlike OpenFOAM, the boundary values of @p alpha are NOT corrected here: an inletOutlet patch
54 * needs the volumetric flux, which @p phi is not. Call correctBoundaryConditions afterwards.
55 */
56void mulesCorrect(
57 nnfvcc::VolumeField<NeoN::scalar>& alpha,
58 const nnfvcc::SurfaceField<NeoN::scalar>& phi,
59 nnfvcc::SurfaceField<NeoN::scalar>& phiCorr,
60 double deltaT,
61 int nLimiterIter,
62 double relaxOld
63);
