15/* @brief Interface unit-normal flux nHatf = nHatfv & Sf.
16 *
17 * @detail nHatfv = gradAlphaf / (|gradAlphaf| + deltaN), with
18 * gradAlphaf = interpolate(grad(alpha1)) (Gauss-Green grad, linear face interpolation) and
19 * deltaN = 1e-8 / cbrt(mean(cell volume)). Follows interfaceProperties::calculateK
20 * without the contact-angle correction. The gradient is summed in OpenFOAM's face order with
21 * OpenFOAM's linear weights, so Serial results match OpenFOAM to the last bit even where
22 * gradAlpha is round-off, which the 1/deltaN normalisation amplifies. Boundary values use the
23 * gaussGrad boundary correction.
24 *
25 * The weights (and vanLeerAlphaFlux's owner-to-neighbour deltas) are copied from the OpenFOAM
26 * mesh in @p rt to the device once and cached in the NeoN mesh's stencil database.
27 */
28nnfvcc::SurfaceField<NeoN::scalar>
29computeNHatf(RunTime& rt, const nnfvcc::VolumeField<NeoN::scalar>& alpha1);
