17/* @brief Interface unit-normal flux nHatf = nHatfv & Sf.
18 *
19 * @detail nHatfv = gradAlphaf / (|gradAlphaf| + deltaN), with
20 * gradAlphaf = interpolate(grad(alpha1)) (Gauss-Green grad, linear face interpolation) and
21 * deltaN = 1e-8 / cbrt(mean(cell volume)). Follows interfaceProperties::calculateK
22 * without the contact-angle correction. The gradient is summed in OpenFOAM's face order with
23 * OpenFOAM's linear weights, so Serial results match OpenFOAM to the last bit even where
24 * gradAlpha is round-off, which the 1/deltaN normalisation amplifies. Boundary values use the
25 * gaussGrad boundary correction.
26 *
27 * The weights (and vanLeerAlphaFlux's owner-to-neighbour deltas) are copied from the OpenFOAM
28 * mesh in @p rt to the device once and cached in the NeoN mesh's stencil database.
29 */

31computeNHatf(RunTime& rt, const nnfvcc::VolumeField<NeoN::scalar>& alpha1);

132/* @brief Bounded explicit MULES solve, Foam::MULES::explicitSolve (MULESTemplates.C).
133 *
134 * @detail rho == 1, Sp == Su == 0, static mesh, Euler time step, extremaCoeff ==
135 * boundaryExtremaCoeff == smoothLimiter == 0. As in OpenFOAM, @p alpha (psi, the current
136 * corrector's field) gives the upwind flux phiBD and the local extrema, while @p alphaOld
137 * (psi.oldTime(), alpha at the start of the time step) enters the bound right-hand sides and
138 * the update alpha = (alphaOld*rDeltaT - surfaceIntegrate(alphaPhi))/rDeltaT. Both are the same
139 * field for the first corrector (nAlphaCorr == 1); @p alphaOld may alias @p alpha.
140 * @p phi is the volumetric flux: it defines the upwind (donor) flux and is the BoundaryContext
141 * "phi" for alpha.correctBoundaryConditions, which runs on entry and exit (as in OpenFOAM).
142 * Limits @p alphaPhi in place (high-order flux in, limited flux out) and advances @p alpha
143 * conservatively.
144 *
145 * Boundary treatment (MULES::limiter): patches that fix the value (NeoN fixesValue, plus
146 * inletOutlet, which is a mixed patch and fixesValue() in OpenFOAM) widen the local extrema of
147 * their face cells by the patch value. The boundary correction flux is zero (phiBD_b ==
148 * alphaPhi_b), so the boundary limiter is irrelevant. Coupled (processor) patches throw; wedge
149 * patches do not exist in NeoN.
150 */

162/* @brief MULES::correct (CMULESTemplates.C) for the VoF path, psiMax == 1, psiMin == 0.
163 *
164 * @detail Limits the correction flux @p phiCorr (internal and boundary faces) so that applying
165 * it keeps alpha bounded, then applies it: alpha = (alpha*rDeltaT - surfaceIntegrate(phiCorr))
166 * / rDeltaT. @p phi plays the role of OpenFOAM's limiterCorr phi argument (interFoam passes
167 * alphaPhiUn): a boundary face is limited only where phi_b + phiCorr_b > SMALL^2 (outlets).
168 * Fixed-value / inletOutlet patches widen the local extrema as in mulesExplicitSolve; coupled
169 * patches throw. @p relaxOld blends the result with the pre-correction field (interFoam
170 * aCorr > 0 branch, 0.5); 0 disables it.
171 *
172 * Unlike OpenFOAM, the boundary values of @p alpha are NOT corrected here: an inletOutlet patch
173 * needs the volumetric flux, which @p phi is not. Call correctBoundaryConditions afterwards.
174 */

184/* @brief Flow and interface Courant numbers of advectorVoF's setDeltaT.H, as {CoNum, alphaCoNum}.
185 *
186 * @detail sumPhi = fvc::surfaceSum(mag(phi)), CoNum = 0.5*gMax(sumPhi/V)*deltaT
187 * (CourantNo.H) and alphaCoNum = 0.5*gMax(pos(alpha - 0.01)*pos(0.99 - alpha)*sumPhi/V)*deltaT
