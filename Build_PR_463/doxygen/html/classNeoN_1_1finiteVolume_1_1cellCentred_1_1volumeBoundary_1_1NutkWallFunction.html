Detailed Description

k-based turbulent viscosity wall function BC.

Mirrors Foam::nutkWallFunctionFvPatchScalarField: derives y⁺ from k rather than |∂U/∂n|, making it the companion to kqRWallFunction for kEpsilon flows.

Required BoundaryContext fields:

  • "k" VolumeField<scalar> — turbulent kinetic energy
  • "nu" VolumeField<scalar> — laminar viscosity, boundary values
  • "nearWallDist" VolumeField<scalar> — cell-to-wall distance y, boundary values

Single-patch-corner only.
