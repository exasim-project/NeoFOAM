\doxysubsection{Detailed Description}
Neo\+FOAM-\/native outer PIMPLE loop control. 

Reads n\+Outer\+Correctors and residual\+Control from the fv\+Solution PIMPLE subdict. Applies per-\/field absolute-\/\+OR-\/relative convergence; skips the check on the first iteration; runs an extra final pass after convergence so \texorpdfstring{$\ast$}{*}\+Final factors fire. Residuals are fed directly via loop(residuals) — no Open\+FOAM round-\/trip.
