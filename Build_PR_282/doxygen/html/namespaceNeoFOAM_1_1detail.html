Write one row of a flat Vector dump.

Format mirrors the proc-face dumps: "0 <index> <value...>". The leading 0 is a placeholder "patch" column so the bisect script's awk numerical comparator (which skips columns 1-2 as integer headers) treats <index> as a column to skip and <value...> as the columns to compare.
