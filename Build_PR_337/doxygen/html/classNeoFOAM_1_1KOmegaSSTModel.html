Detailed Description

TurbulenceModel-factory wrapper for k-omega SST.

Owns k, omega and nut; reads them from disk in the constructor, delegates physics to KOmegaSST. Registered as "kOmegaSST" in the TurbulenceModel factory so TurbulenceModel::create() can instantiate it from a RAS turbulenceProperties block.
