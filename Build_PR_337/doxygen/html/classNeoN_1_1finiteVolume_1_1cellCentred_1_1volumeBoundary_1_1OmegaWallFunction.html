Detailed Description

Omega wall function boundary condition.

Requires BoundaryContext fields: "k", "nu", "nearWallDist". The no-arg correctBoundaryCondition() overload is a no-op.

Known limitations:

  • Single-patch-corner only: each wall cell is assumed to see at most one wall-function face.
  • G production-term feedback is not applied here; it is handled by kOmegaSST internally.
