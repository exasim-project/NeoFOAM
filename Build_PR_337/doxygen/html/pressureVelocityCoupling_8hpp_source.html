17/* @brief ensure that the HbyA does not violate boundary velocity constraint
18 *
19 * @detail
20 * See https://openfoamwiki.net/index.php/SimpleFoam for details
21 *
22 * Cite:
23 * The velocity at the boundary face should satisfy following equation:
24 * \bold{u}|_{bf} = \frac{\bold {H[u] }}{a_P }|_{bf} - \frac{\nabla p{}}{a_P }|_{bf}
25 * The subscript bf denoted that the quantity is evaluated at the boundary face. The function
26 * constrainHbyA ensures that the field <math> \frac{\bold {H[u] }}{a_P }|_{bf} </math> does not
27 * violate the above equation. The boundary condition fixedFluxExtrapolatedPressure sets the
28 * pressure gradient in order that the above equation is satisfied. If we cannot modify the
29 * velocity, the function sets the field <math> \frac{\bold {H[u] }}{a_P }|_{bf} = \bold{u}|_{bf}
30 * </math> in order that the field <math> \frac{\bold {H[u] }}{a_P }|_{bf} </math> does not
31 * contradict the zero gradient boundary condition which should be applied for the pressure if the
32 * velocity is fixed.
33 */

59/* @brief computes phi = phiHbyA - pEqn.flux();
60 * where pEqn.flux() = (orthogonal matrix-coefficient flux) + faceFluxCorrection
61 *
62 * @detail The pressure Laplacian defers its non-orthogonal snGrad correction to the matrix
63 * RHS (deferred correction) and stashes the per-face correction flux in the linear system
64 * (LinearSystem::faceFluxCorrection(), the OpenFOAM fvMatrix::faceFluxCorrectionPtr_ analogue).
65 * This reconstruction adds it back; the orthogonal-only reconstruction would otherwise leave
66 * div(phi) = div(correctionFlux) != 0, inflating the continuity error on non-orthogonal meshes
