\doxysubsection{Detailed Description}
Turbulence\+Model-\/factory wrapper for k-\/epsilon. 

Owns k, epsilon and nut; reads them from disk in the constructor, delegates physics to \doxylink{classNeoFOAM_1_1KEpsilon}{KEpsilon}. Registered as "{}k\+Epsilon"{} in the \doxylink{classNeoFOAM_1_1TurbulenceModel}{Turbulence\+Model} factory so \doxylink{classNeoFOAM_1_1TurbulenceModel_a49dee8641d6055c7fa2b88be94e8448a}{Turbulence\+Model\+::create()} can instantiate it from a RAS turbulence\+Properties block.
