\doxysubsection{Detailed Description}
Epsilon wall function boundary condition.

Known limitations\+:
\begin{DoxyItemize}
\item Single-\/patch-\/corner only\+: each wall cell is assumed to see at most one wall-\/function face.
\item G production-\/term feedback is not handled here; it is written by the parent k\+Epsilon model. 
\end{DoxyItemize}
