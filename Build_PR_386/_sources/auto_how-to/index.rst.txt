How-to guides
=============

Goal-oriented runnable recipes. Each page answers one question and
assumes you already know what you're trying to do — for an end-to-end
learning path, read the :doc:`tutorials </auto_tutorials/index>`
instead.

Every page is a Python script executed at documentation build time
against the cases shipped under ``tutorials/`` in the repo. Download
the ``.py`` or rendered notebook to run it locally.

A model-owned interface is that shared gather point: one model owns it via @&lt;owner&gt;.interface (the body that decides how the pieces combine), other models plug in with @&lt;model&gt;.contributes(&lt;interface&gt;), and a consumer injects the interface and calls it to get the single combined result. New models plug in without the owner, the consumer, or the other models changing.">
