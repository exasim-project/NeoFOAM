Detailed Description

Pressure limits of the compressible solvers, as OpenFOAM's Foam::pressureControl.

Resolves the limits like pressureControl's constructor with pRefRequired = false (what rhoPimpleFoam uses): an absolute pMin/pMax pair wins; otherwise pMax (pMin) is the explicit value, pMaxFactor (pMinFactor) times the largest (smallest) boundary value of p over the patches that fix its value (OpenFOAM counts every mixed patch as fixing it, which NeoN flags with the mixed boundary attribute when its version has it), or, for backward compatibility, the pressure belonging to rhoMax (rhoMin) at the reference density. The factor and rho forms need at least one value-fixing p patch and throw otherwise, as OpenFOAM does.

limit() then clips p where it leaves [pMin, pMax], like pressureControl::limit(). The caller re-evaluates p's boundary conditions afterwards when limit() returns true.

◆ limit()

bool NeoFOAM::PressureControl::limit ( NeoN::finiteVolume::cellCentred::VolumeField< NeoN::scalar > & p) const

Clip the internal values of p to [pMin, pMax].

The extremes are taken over the internal AND boundary values, as OpenFOAM's max(p) does, and p is only touched when one of them is outside the limits. Boundary values are left alone: the caller evaluates p's boundary conditions afterwards, which is what recomputes them (a value-fixing patch keeps its value, as OpenFOAM's assignment to it is a no-op).

Returns
true if limits are configured (even if nothing was clipped), like OpenFOAM.
