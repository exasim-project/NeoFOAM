\doxysubsection{Detailed Description}
Pressure limits of the compressible solvers, as Open\+FOAM\textquotesingle{}s Foam\+::pressure\+Control. 

Resolves the limits like pressure\+Control\textquotesingle{}s constructor with p\+Ref\+Required = false (what rho\+Pimple\+Foam uses)\+: an absolute p\+Min/p\+Max pair wins; otherwise p\+Max (p\+Min) is the explicit value, p\+Max\+Factor (p\+Min\+Factor) times the largest (smallest) boundary value of p over the patches that fix its value (Open\+FOAM counts every mixed patch as fixing it, which \doxylink{namespaceNeoN}{NeoN} flags with the {\ttfamily mixed} boundary attribute when its version has it), or, for backward compatibility, the pressure belonging to rho\+Max (rho\+Min) at the reference density. The factor and rho forms need at least one value-\/fixing p patch and throw otherwise, as Open\+FOAM does.

\doxylink{classNeoFOAM_1_1PressureControl_a6a27951f2a60f6c01acf4a6d2573c95c}{limit()} then clips p where it leaves \mbox{[}p\+Min, p\+Max\mbox{]}, like pressure\+Control\+::limit(). The caller re-\/evaluates p\textquotesingle{}s boundary conditions afterwards when \doxylink{classNeoFOAM_1_1PressureControl_a6a27951f2a60f6c01acf4a6d2573c95c}{limit()} returns true.

Clip the internal values of p to \mbox{[}p\+Min, p\+Max\mbox{]}. 

The extremes are taken over the internal AND boundary values, as Open\+FOAM\textquotesingle{}s max(p) does, and p is only touched when one of them is outside the limits. Boundary values are left alone\+: the caller evaluates p\textquotesingle{}s boundary conditions afterwards, which is what recomputes them (a value-\/fixing patch keeps its value, as Open\+FOAM\textquotesingle{}s assignment to it is a no-\/op).

\begin{DoxyReturn}{Returns}
true if limits are configured (even if nothing was clipped), like Open\+FOAM.
