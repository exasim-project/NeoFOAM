\doxysubsection{Detailed Description}
Neo\+FOAM-\/level wrapper for the k-\/omega SST turbulence model (Menter 1993/2003). 

Mirrors the Open\+FOAM turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1KOmegaSST_a8731bdfb6db9771ba813d4ee039da8e9}{validate()} / turbulence-\/\texorpdfstring{$>$}{>}\doxylink{classNeoFOAM_1_1KOmegaSST_a700c93859285ffe8fced126b0d3006f5}{correct()} interface. Owns all intermediate fields and cached operators. The solver manages the primary fields (k, omega, nut) and calls \doxylink{classNeoFOAM_1_1KOmegaSST_a8731bdfb6db9771ba813d4ee039da8e9}{validate()} once at setup and \doxylink{classNeoFOAM_1_1KOmegaSST_a700c93859285ffe8fced126b0d3006f5}{correct()} after each momentum solve.

\doxylink{structNeoFOAM_1_1KOmegaSST_1_1Coefficients}{Coefficients} follow the 2003 Menter/\+Kuntz/\+Langtry values (same as Open\+FOAM default). Diffusion is written in terms of alpha = 1/sigma so that the inner/outer blending (F1) is applied uniformly — consistent with the Open\+FOAM k\+Omega\+SSTBase convention.

Equivalent to Open\+FOAM\textquotesingle{}s compressible k\+Omega\+SSTBase\+::correct() with alpha = 1\+: ddt(rho, psi) + div(phi, psi) -\/ laplacian(rho\texorpdfstring{$\ast$}{*}\+Dpsi\+Eff, psi) = rho\texorpdfstring{$\ast$}{*}(sources) with the dilatation terms -\/Su\+Sp((2/3) rho divU, k) and -\/Su\+Sp((2/3) rho gamma divU, omega). divU is the divergence of the volumetric flux phi/interpolate(rho). nut stays kinematic.
